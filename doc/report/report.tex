\subsubsection{Histogram Equalization}
Histogram Equalization is a contrast enhancement filter that redistributes the brightness values in an image. To prevent unwanted color shifting, we do it in the YCrCb color space only on the luminance channel then converting back to BGR.

The algorithm calculates the histogram frequencies, the Probability Density Function (PDF), and the Cumulative Distribution Function (CDF). The PDF for a pixel intensity $i$ is calculated as:
\[
PDF(i) = \frac{\text{count}(i)}{\text{total pixels}}
\]
The CDF is then calculated as the cumulative sum of the PDF:
\[
CDF(i) = \sum_{j=0}^{i} PDF(j)
\]
Finally, the new pixel values are computed by scaling the CDF to the 0-255 range:
\[
\text{Output}(x,y) = \text{round}(CDF(I(x,y)) \times 255)
\]

\subsubsection{Lens Distortion}

The filter uses an inverse geometric mapping to simulate lens distortion. For each output pixel $(x, y)$, the source coordinate $(s_x, s_y)$ is calculated through three steps listed below:

\begin{description}
    \item[1. Normalization:] Coordinates are centered and scaled by $R = \sqrt{c_x^2 + c_y^2}$ to maintain similar results for different image sizes:
    \[ d_x = \frac{x - c_x}{R}, \quad d_y = \frac{y - c_y}{R} \]
    \item[2. Distortion:] A radial factor is computed using coefficient $k$:
    \[ \text{dist} = 1 + k(d_x^2 + d_y^2) \]
    Positive $k$ produces barrel distortion, while negative $k$ produces pincushion effects.
    \item[3. Mapping:] Coordinates are scaled back to source pixel space:
    \[ s_x = d_x \cdot \text{dist} \cdot R + c_x, \quad s_y = d_y \cdot \text{dist} \cdot R + c_y \]
\end{description}
Pixels are then sampled using nearest-neighbor interpolation. The computational complexity is $O(W \times H)$.

\subsubsection{Posterize}

Reduces color depth by quantizing each channel into $L = 8$ discrete levels. A 256-entry LUT is computed once to improve performance.

\begin{description}
    \item[1. Step Calculation:] The spacing between levels:
    \[ \text{step} = \frac{255}{L - 1} \approx 36.4 \]
    \item[2. LUT Construction:] Each intensity $i$ is snapped to the nearest level index, then scaled back:
    \[ \text{level}_i = \text{round}\!\left(\frac{i}{\text{step}}\right), \quad \text{LUT}[i] = \text{round}(\text{level}_i \times \text{step}) \]
    \item[3. Pixel Remapping:] Each BGR channel is independently mapped:
    \[ \text{Output}_{c}(x, y) = \text{LUT}[\text{Input}_{c}(x, y)], \quad c \in \{B, G, R\} \]
\end{description}
Complexity: $O(W \times H)$ for the pixel pass, plus $O(256)$ for LUT construction.

\subsubsection{Vignette Blur}

Softens edges while keeping the center sharp. Implemented as a two step process: a 15×15 box blur followed by a radial blend.

\begin{description}
    \item[1. Box Blur:] For interior pixels (7-pixel border excluded), compute the 15×15 mean kernel convolution.
    \[ \text{Blur}(x,y) = \frac{1}{225} \sum_{dy=-7}^{7} \sum_{dx=-7}^{7} \text{Input}(x+dx,\, y+dy) \]
    \item[2. Radial Mask:] Normalize the distance from center $(c_x, c_y)$ by the corner radius $R$:
    \[ d = \frac{\sqrt{(x-c_x)^2 + (y-c_y)^2}}{R}, \quad d \in [0, 1] \]
    The center maps to 0 (no blur) and corners to 1 (full blur).
    \item[3. Blending:] Linearly interpolate between original and blurred using $d$ as the weight:
    \[ \text{Output}(x,y) = \text{Input}(x,y) \cdot (1-d) + \text{Blur}(x,y) \cdot d \]
\end{description}
Complexity: $O(W \times H)$ since the blur and blend are computed in a single pass.

\subsubsection{Threshold Filter}

The Threshold filter converts the image into a binary black-and-white representation using grayscale luminosity computation and threshold comparison. It is commonly used in OCR systems, segmentation, and preprocessing pipelines.

\[
L = 0.299R + 0.587G + 0.114B
\]

\[
\text{Output} =
\begin{cases}
255, & \text{if } L > T \\
0, & \text{otherwise}
\end{cases}
\]

The algorithm processes each pixel independently with linear complexity:

\[
O(W \times H)
\]

\subsubsection{Diffuse Filter}

The Diffuse filter creates a frosted-glass effect by randomly replacing each pixel with a neighboring pixel within a selected radius.
\[
(x', y') = (x + r_x,\ y + r_y)
\]

The filter produces stochastic local distortions while maintaining linear computational complexity:
\[
O(W \times H)
\]

\subsubsection{Crosshatch Filter}

The Crosshatch filter simulates sketch-style rendering using procedural diagonal line generation based on pixel coordinates.
\[
(x + y) \bmod n = 0
\]
Darker image regions generate denser hatch patterns, creating a pen-and-ink drawing effect.
\[
O(W \times H)
\]

O(W \times H)
