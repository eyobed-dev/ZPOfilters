\subsubsection{Histogram Equalization}
Histogram Equalization enhances image contrast by redistributing the brightness values. To prevent unwanted color shifting, the algorithm operates in the YCrCb color space, applying the equalization only to the luminance channel before converting back to BGR.

The algorithm calculates the histogram frequencies, the Probability Density Function (PDF), and the Cumulative Distribution Function (CDF). The PDF for a pixel intensity $i$ is calculated as:
\[
PDF(i) = \frac{\text{count}(i)}{\text{total pixels}}
\]
The CDF is then calculated as the cumulative sum of the PDF:
\[
CDF(i) = \sum_{j=0}^{i} PDF(j)
\]
Finally, the new remapped pixel value is computed by scaling the CDF to the 0-255 range:
\[
\text{Output}(x,y) = \text{round}(CDF(I(x,y)) \times 255)
\]

\subsubsection{Lens Distortion}

The filter uses an inverse geometric mapping to simulate lens distortion. For each output pixel $(x, y)$, the source coordinate $(s_x, s_y)$ is calculated through three steps listed below:

\begin{description}
    \item[1. Normalization:] Coordinates are centered and scaled by $R = \sqrt{c_x^2 + c_y^2}$:
    \[ d_x = \frac{x - c_x}{R}, \quad d_y = \frac{y - c_y}{R} \]
    \item[2. Distortion:] A radial factor is computed using coefficient $k$:
    \[ \text{dist} = 1 + k(d_x^2 + d_y^2) \]
    Positive $k$ produces barrel distortion, while negative $k$ produces pincushion effects.
    \item[3. Mapping:] Coordinates are scaled back to source pixel space:
    \[ s_x = d_x \cdot \text{dist} \cdot R + c_x, \quad s_y = d_y \cdot \text{dist} \cdot R + c_y \]
\end{description}
Pixels are sampled using nearest-neighbor interpolation. The computational complexity is $O(W \times H)$.

\subsubsection{Posterize}

Reduces color depth by quantizing each channel into $L = 8$ discrete levels. A 256-entry LUT is computed once to improve performance.

\begin{description}
    \item[1. Step Calculation:] The spacing between levels:
    \[ \text{step} = \frac{255}{L - 1} \approx 36.4 \]
    \item[2. LUT Construction:] Each intensity $i$ is snapped to the nearest level index, then scaled back:
    \[ \text{level}_i = \text{round}\!\left(\frac{i}{\text{step}}\right), \quad \text{LUT}[i] = \text{round}(\text{level}_i \times \text{step}) \]
    \item[3. Pixel Remapping:] Each BGR channel is independently mapped:
    \[ \text{Output}_{c}(x, y) = \text{LUT}[\text{Input}_{c}(x, y)], \quad c \in \{B, G, R\} \]
\end{description}
Complexity: $O(W \times H)$ for the pixel pass, plus $O(256)$ for LUT construction.

\subsubsection{Vignette Blur}

Softens edges while keeping the center sharp. Implemented as a two step process: a 15×15 box blur followed by a radial blend.

\begin{description}
    \item[1. Box Blur:] For interior pixels (7-pixel border excluded), compute the 15×15 mean kernel convolution.
    \[ \text{Blur}(x,y) = \frac{1}{225} \sum_{dy=-7}^{7} \sum_{dx=-7}^{7} \text{Input}(x+dx,\, y+dy) \]
    \item[2. Radial Mask:] Normalize the distance from center $(c_x, c_y)$ by the corner radius $R$:
    \[ d = \frac{\sqrt{(x-c_x)^2 + (y-c_y)^2}}{R}, \quad d \in [0, 1] \]
    The center maps to 0 (no blur) and corners to 1 (full blur).
    \item[3. Blending:] Linearly interpolate between original and blurred using $d$ as the weight:
    \[ \text{Output}(x,y) = \text{Input}(x,y) \cdot (1-d) + \text{Blur}(x,y) \cdot d \]
\end{description}
Complexity: $O(W \times H)$ since the blur and blend are computed in a single pass.

\subsection{Adar's Filters}
Adar's contributions focus on manual pixel manipulation using native loops, avoiding optimized OpenCV functions for educational purposes.
\begin{itemize}
    \item \textbf{Relief Emboss:} Creates a 3D gray relief texture by subtracting the bottom-right neighboring pixel from the top-left neighbor and adding an offset of 128 to center the result.
    \item \textbf{Dodge:} Implements the classic Color Dodge blend formula: \texttt{(pixel * 255) / max(1, 255 - pixel)}. This blows out the highlights and drastically increases contrast.
    \item \textbf{Swirl:} Warps the image into a vortex by converting Cartesian coordinates to Polar coordinates, applying a nonlinear rotational offset based on the radius, and converting back to sample the pixel.
    \item \textbf{Bloom:} Extracts bright pixels (intensity $>$ 180) and applies a brute-force nested 7x7 loop to blur them. The resulting glow is then added directly back to the original image.
\end{itemize}

\subsubsection{Threshold Filter}

The Threshold filter converts the image into a binary black-and-white representation using grayscale luminosity computation and threshold comparison. It is commonly used in OCR systems, segmentation, and preprocessing pipelines.

\[
L = 0.299R + 0.587G + 0.114B
\]

\[
\text{Output} =
\begin{cases}
255, & \text{if } L > T \\
0, & \text{otherwise}
\end{cases}
\]

The algorithm processes each pixel independently with linear complexity:

\[
O(W \times H)
\]

\subsubsection{Diffuse Filter}

The Diffuse filter creates a frosted-glass effect by randomly replacing each pixel with a neighboring pixel within a selected radius.

\[
(x', y') = (x + r_x,\ y + r_y)
\]

The filter produces stochastic local distortions while maintaining linear computational complexity:

\[
O(W \times H)

\subsubsection{Posterize}

Reduces color depth by quantizing each channel into $L = 8$ discrete levels. A 256-entry LUT is computed once to improve performance.

\begin{description}
    \item[1. Step Calculation:] The spacing between levels:
    \[ \text{step} = \frac{255}{L - 1} \approx 36.4 \]
    \item[2. LUT Construction:] Each intensity $i$ is snapped to the nearest level index, then scaled back:
    \[ \text{level}_i = \text{round}\!\left(\frac{i}{\text{step}}\right), \quad \text{LUT}[i] = \text{round}(\text{level}_i \times \text{step}) \]
    \item[3. Pixel Remapping:] Each BGR channel is independently mapped:
    \[ \text{Output}_{c}(x, y) = \text{LUT}[\text{Input}_{c}(x, y)], \quad c \in \{B, G, R\} \]
\end{description}
Complexity: $O(W \times H)$ for the pixel pass, plus $O(256)$ for LUT construction.

\subsubsection{Vignette Blur}

Softens edges while keeping the center sharp. Implemented as a two step process: a 15×15 box blur followed by a radial blend.

\begin{description}
    \item[1. Box Blur:] For interior pixels (7-pixel border excluded), compute the 15×15 mean kernel convolution.
    \[ \text{Blur}(x,y) = \frac{1}{225} \sum_{dy=-7}^{7} \sum_{dx=-7}^{7} \text{Input}(x+dx,\, y+dy) \]
    \item[2. Radial Mask:] Normalize the distance from center $(c_x, c_y)$ by the corner radius $R$:
    \[ d = \frac{\sqrt{(x-c_x)^2 + (y-c_y)^2}}{R}, \quad d \in [0, 1] \]
    The center maps to 0 (no blur) and corners to 1 (full blur).
    \item[3. Blending:] Linearly interpolate between original and blurred using $d$ as the weight:
    \[ \text{Output}(x,y) = \text{Input}(x,y) \cdot (1-d) + \text{Blur}(x,y) \cdot d \]
\end{description}
Complexity: $O(W \times H)$ since the blur and blend are computed in a single pass.

\subsubsection{Bloom Filter}
\textbf{Core model}
\[
M(x)=\mathbf{1}_{I_g(x)\ge T},\quad B=I\odot M,\quad G=G_{\sigma}*B,\quad I'=I+\alpha G
\]
\textbf{Notation} \(T\): threshold, \(\sigma\): blur spread, \(\alpha\): glow strength, \(I'\): output.

\textbf{Pixel-level transformation}
\[
I'_c(x,y)=I_c(x,y)+\alpha\sum_{i=-r}^{r}\sum_{j=-r}^{r}G_{\sigma}(i,j)\,B_c(x+i,y+j)
\]
Only bright pixels feed the glow layer; high \(T\) can suppress bloom even with high \(\alpha\).

\textbf{Algorithm (implementation)}
\begin{verbatim}
bright = image * (gray >= T)
glow = convolve(bright, gaussian_kernel(k, sigma))
out = clip(image + alpha * glow)
\end{verbatim}
\textbf{Implementation note} Convert to BGR \texttt{uint8}, clamp \(T,\alpha,\sigma\) to safe ranges, run blur/blend in float, then clip and cast back to \([0,255]\).

\subsubsection{Orton Effect Filter}
\textbf{Core model}
\[
S = 255 - \frac{(255-I)(255-B)}{255},\quad B=G_{\sigma}*I,\quad I'=(1-\alpha)I+\alpha S
\]
\textbf{Notation} \(B\): blurred image, \(S\): screen blend, \(\sigma\): blur spread, \(\alpha\): mix strength.

\textbf{Pixel-level transformation}
\[
\begin{aligned}
B_c(x,y)&=\sum_{i=-r}^{r}\sum_{j=-r}^{r}G_{\sigma}(i,j)\,I_c(x+i,y+j),\\
S_c(x,y)&=255-\frac{(255-I_c(x,y))(255-B_c(x,y))}{255},\\
I'_c(x,y)&=(1-\alpha)I_c(x,y)+\alpha S_c(x,y).
\end{aligned}
\]

\textbf{Algorithm (implementation)}
\begin{verbatim}
blur = convolve(image, gaussian_kernel(k, sigma))
screen = 255 - ((255-image)*(255-blur)/255)
out = clip((1-alpha)*image + alpha*screen)
\end{verbatim}
\textbf{Implementation note} Convert to BGR \texttt{uint8}, clamp \(\alpha,\sigma\), compute blur and screen blend in float, then clip and cast to \texttt{uint8}.

\subsubsection{Gamma Filter}
\textbf{Core model}
\[
V_{\text{out}} = A\,V_{\text{in}}^{\gamma},\qquad
I' = 255\left(\frac{I}{255}\right)^{1/\gamma}
\]
\textbf{Notation} \(\gamma\): tone-curve exponent, \(A\): scale (usually 1), \(I\in[0,255]\): 8-bit input.
\textbf{Why \(0..255\)} 8-bit \texttt{uint8} images have 256 levels; divide by 255 to normalize to \([0,1]\), then multiply by 255 to return.

\textbf{Pixel-level transformation}
\[
I'_{c}(x,y)=255\left(\frac{I_{c}(x,y)}{255}\right)^{1/\gamma}
\]
\(\gamma<1\): brighter midtones, \(\gamma>1\): darker midtones.

\textbf{Algorithm (implementation)}
\begin{verbatim}
lut[i] = round(((i/255.0)**(1.0/gamma))*255)
out = lut[image]
\end{verbatim}
\textbf{Implementation note} Convert to BGR \texttt{uint8}, clamp \(\gamma\), build a 256-entry LUT in float, then apply LUT and keep output in \([0,255]\) \texttt{uint8}.

\subsubsection{Dodge Filter}
\textbf{Core model}
\[
I' \approx \frac{255\,I}{255-sI}
\]
\textbf{Notation} \(s\): dodge strength, \(I\): input intensity, \(I'\): output intensity.

\textbf{Pixel-level transformation}
\[
I'_{c}(x,y)=\mathrm{clip}\!\left(\frac{255\,I_{c}(x,y)}{\max(255-s\,I_{c}(x,y),1)}\right)
\]
Higher \(s\) strongly boosts highlights and may clip to white.

\textbf{Algorithm (implementation)}
\begin{verbatim}
denom = 255 - strength*image
out = clip((image*255) / max(denom, 1))
\end{verbatim}
\textbf{Implementation note} Convert to BGR \texttt{uint8}, clamp strength \(s\), compute in float with denominator floor for stability, then clip and cast to \texttt{uint8}.
